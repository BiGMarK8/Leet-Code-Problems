# LeetCode Problems

My solutions to [LeetCode](https://leetcode.com/) problems, written in Python 3.

## About

This repo is where I track my LeetCode practice. I'm working through problems to
sharpen my data structures, algorithms, and problem-solving for software
engineering interviews, and keeping each solution here as a record of progress.

## Structure

Each solution lives in its own file named `NNNN-problem-slug.py`, where `NNNN`
is the zero-padded LeetCode problem number. Every file includes:

- A header docstring with the problem link, difficulty, topics, and a short
  restatement of the problem.
- The approach and its time/space complexity.
- The `Solution` class exactly as submitted to LeetCode.
- A runnable `__main__` block with test cases, so each file can be checked
  locally.

## Language

- Python 3
